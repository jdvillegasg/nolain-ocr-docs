    Troubleshoot the dashboard workflow

    Use the message visible on nolainocr.com to choose a recovery path. These steps stay on the user side: they restore a normal workflow without exposing service credentials or operator procedures.

    You cannot open the dashboard

    Visible symptom: sign-in succeeds but the dashboard sends you back to verify email, or login is rejected.

    1. If you registered with email, open the verification message and follow the link, then sign in at nolainocr.com/login.
    2. If the message never arrived, wait a few minutes, check spam, and retry from the verification screen.
    3. Use Forgot password when the password is the problem. Reset links expire; request a new one if the form rejects the token.

    Google sign-in goes through Google’s consent screen and returns to nolainocr. If that loop fails, try email sign-in or contact with the approximate time — not your password.

    Upload is refused

    Visible symptom: the dashboard rejects the file, or extraction never starts.

    • Use PDF, JPEG, or PNG.
    • Confirm the file is under the size the upload control accepts. Very large scans may need to be split with the free PDF tools first.
    • Confirm the page count is within your plan’s per-document cap. The account page shows the current limit.

    Extraction stops on a plan limit

    Visible symptom: the product says you are out of pages, or asks you to upgrade.

    Monthly quota is used before top-up pages. If both are empty, open Account, upgrade or buy a pack, then retry. A preview of pages does not itself consume allowance; a finished extraction does. See Plans and page limits.

    The table looks wrong

    Visible symptom: columns duplicate, names are noisy, or two document types are mixed in one sheet.

    The batch must share a layout. Split unrelated templates into separate runs. If one PDF interleaves two-page documents, set pages per document to match the repeating unit (1–4) and extract again. Reset the dashboard between unlike batches so the previous schema does not linger in the session.

    Progress sits still on a large job

    Visible symptom: a multi-page run shows a progress indicator for a long time, then completes or fails.

    Large stacks are processed in the background so the browser is not left waiting on a single request. Stay on the dashboard until the results panel fills. If the job fails, retry once. If it fails again, contact with the approximate time and the visible error text. Do not include document contents.

    Export is empty or Google Sheets does not open

    Visible symptom: download produces no useful file, or the Google Sheets path asks for permission and stops.

    Extract successfully before export. Excel and CSV come from the current results table. Google Sheets needs a Google account permission in the browser; deny or block that prompt and the send will not finish. Retry after granting access, or download Excel instead.

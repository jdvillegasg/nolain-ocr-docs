    Frontend Components Architecture

    This document details the frontend architecture, including React components, state management, routing, and how the frontend interacts with the backend.

    Technology Stack

    Core Technologies

    • React 18 - UI library
    • TypeScript - Type safety
    • Vite 7 - Build tool and dev server
    • Tailwind CSS - Utility-first styling

    Routing & Navigation

    • TanStack Router - Type-safe routing with lazy-loaded pages
    • Custom route protection (auth required, email verified)

    State Management

    • Zustand - Lightweight state management with persist middleware
    • TanStack Query - Server state caching (subscription status, top-up packs)

    UI Components

    • Radix UI - Accessible component primitives
    • Framer Motion - Animations
    • Lucide React - Icon library
    • marked - Blog markdown rendering

    Backend Integration

    • Custom Fetch Wrapper (lib/api.ts) - API client with auth headers and timing
    • Supabase JS - Google OAuth on the client
    • Google Sheets API - Client-side export from dashboard (VITE_GOOGLE_CLIENT_ID)

    State Management Architecture

    Zustand Stores

    1. Auth Store (stores/authStore.ts)

    Purpose: Manages user authentication and session state

    State:

    {
  user: User | null
  isAuthenticated: boolean
  isLoading: boolean
  pendingEmail: string | null
}

    Actions: - login(email, password) - Email/password authentication - register(email, password, fullName) - Create new account - logout() - End session and cleanup - resetPassword(email) - Request password reset - updatePassword(token, password) - Change password - Google OAuth handled via Supabase client + /auth/callback page

    Persistence: localStorage (auth-storage)

    2. Dashboard Store (stores/dashboardStore.ts)

    Purpose: Manages document upload and extraction workflow

    State:

    {
  uploadedFiles: UploadedFile[]
  extractedText: ExtractedData | null
  templateGroups: TemplateGroup[]
  isLoading: boolean
  taskId: string | null
  extractionProgress: number
}

    Actions: - uploadFiles(files, userId) - Upload PDFs/images - extractText() - Start extraction (sync single or async multi via SSE) - resetDashboard() - Clear all state - exportCurrentData(format) - Export Excel/CSV/JSON

    Persistence: localStorage (dashboard-storage)

    Features: - Handles both single and multi-page uploads - Manages template grouping (up to 4 pages per document) - SSE connection to /api/stream/{task_id} for async progress

    3. Request Store (stores/requestStore.ts)

    Purpose: Tracks API request timing from X-Process-Time response header

    Persistence: None (session only)

    TanStack Query

    Used for: - Subscription status (/subscription-status) - Top-up pack catalog (/topup-packs) - Background refetching and cache invalidation

    Routing Structure

    Public Routes

    Path Page
    / LandingPage (OAuth/password-reset redirect detection)
    /login LoginForm
    /register RegisterForm
    /auth/callback AuthCallbackPage (Google OAuth)
    /forgot-password PasswordResetPage
    /reset-password PasswordResetConfirmPage
    /verify-email EmailVerificationPage
    /registration-success RegistrationSuccessPage
    /contact ContactPage
    /privacy-policy PrivacyPolicyPage
    /blog BlogPage
    /blog/$slug BlogPostPage
    /tools ToolsIndexPage
    /tools/* 14 individual tool pages
    /solutions/* 8 solution marketing pages

    Protected Routes

    Path Page Requirements
    /dashboard DashboardPage Auth + email verified
    /account AccountPage Auth + email verified

    Note: /analytics (StatisticsPage) is commented out — the statistics API was removed.

    Route Protection

    beforeLoad: ({ context }) => {
  if (!context.auth.isAuthenticated) {
    throw redirect({ to: '/' })
  }
  if (!context.auth.user?.email_confirmed_at) {
    throw redirect({ to: '/verify-email' })
  }
}

    Page Components

    Landing Page

    • Hero section, pricing tiers (Free, Pro, Pro Plus)
    • Top-up pricing section (#top-up-pricing)
    • OAuth and email verification redirect detection
    • Solution page links

    Dashboard Page

    Workflow: 1. Upload documents (PDF/images) 2. Configure template groups (pages per document, up to 4) 3. Extract data (sync for single page, async with SSE for multi-page) 4. View results in DataTable 5. Export to Excel, CSV, JSON, or Google Sheets

    Real-time Updates: - SSE connection to /api/stream/{task_id} for async extraction progress

    Account Page

    • Current subscription tier and usage statistics
    • Pro/Pro+ upgrade and plan change
    • Top-up page pack purchases
    • Stripe billing portal access
    • Subscription cancellation

    Free Tools (/tools/*)

    100% browser-side — no backend calls, no auth required: - PDF: merge, split, to/from images, delete pages - Image: resize/crop, rotate, format convert - Data: JSON formatter, CSV to Markdown, text diff/stats - Utility: QR code, currency converter, world time

    Blog

    • Markdown files in src/data/blog-posts/*.md
    • Registered in src/data/blogPosts.ts
    • Build generates sitemap and prerenders pages

    API Integration

    API Client (lib/api.ts)

    Features: - Base URL: /api (nginx-proxied) - Injects X-Access-Token and X-User-Id from authStore - Request timing via X-Process-Time header - Error handling with toast notifications

    Key Methods:

    // Auth
login, register, logout, resetPassword, updatePassword

// Files
uploadFile, uploadFiles, getPageImageUrl

// Extraction
extractImage, extractMultipleImages

// Export
exportCurrentData

// Subscription
createCheckoutSession, getSubscriptionStatus, cancelSubscription
updateSubscription, createBillingPortalSession

// Top-up
getTopupPacks, createTopupCheckout, confirmTopupCheckout

    Build & Development

    Vite Configuration

    • Dev Server: Port 3000
    • Proxy: /api → http://localhost:8000
    • Path Alias: @ → ./src

    Environment Variables (baked at build time)

    VITE_SUPABASE_URL
VITE_SUPABASE_ANON_KEY
VITE_GOOGLE_CLIENT_ID
VITE_STRIPE_PRO_PRICE_ID
VITE_STRIPE_PRO_PLUS_PRICE_ID
VITE_PRICE_PRO_VALUE / VITE_PRICE_PRO_PLUS_VALUE
VITE_FREE/PRO/PRO_PLUS_PAGES_PER_DOCUMENT
VITE_FREE/PRO/PRO_PLUS_PAGES_PER_MONTH

    Note: Frontend display defaults may differ from backend defaults when env vars are unset.

    Build Process

    npm install
npm run dev        # Dev server
npm run build      # TypeScript + Vite build + sitemap + prerender
npm run preview    # Preview production build

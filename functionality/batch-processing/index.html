    Batch Processing with Mistral AI

    Efficient processing of large document batches using Mistral AI's Batch API.

    When to Use Batch API

    Threshold: More than 50 images

    Benefits: - Parallel processing by Mistral AI - Lower cost per request - Automatic retries - Progress tracking

    Batch API Flow

    1. Create Batch Job

    # Upload images to Mistral
file_ids = []
for image in images:
    file = mistral_client.files.upload(file=image)
    file_ids.append(file.id)

# Create batch job
batch = mistral_client.batch.jobs.create(
    input_files=file_ids,
    endpoint="/v1/chat/completions",
    model="mistral-small-latest",
    metadata={"user_id": user_id}
)

    2. Poll for Completion

    while batch.status in ["queued", "running"]:
    time.sleep(10)
    batch = mistral_client.batch.jobs.get(batch.id)

    # Update progress
    progress = (batch.completed_requests / batch.total_requests) * 100
    publish_progress(task_id, progress)

    3. Retrieve Results

    # Download results
results_content = mistral_client.files.download(batch.output_file)

# Parse results
results = []
for line in results_content.splitlines():
    result = json.loads(line)
    results.append(result)

    Processing Strategies

    Small Batch (< 50 images)

    Method: Parallel async requests

    Code:

    import asyncio

async def process_small_batch(images):
    tasks = [extract_text_async(img) for img in images]
    results = await asyncio.gather(*tasks)
    return results

    Time: ~0.5-1 second per image

    Large Batch (≥ 50 images)

    Method: Mistral Batch API

    Time: 5-15 minutes total

    Advantages: - More efficient at scale - Lower API costs - Automatic parallelization by Mistral

    Template Groups

    Combine multiple pages into single documents.

    Example:

    {
  "template_group": [
    ["page_1.jpg", "page_2.jpg"],      // Doc 1
    ["page_3.jpg", "page_4.jpg"]       // Doc 2
  ]
}

    Processing: 1. Combine pages vertically 2. Send combined image to Mistral 3. Extract as single document 4. Repeat for each group

    Limit: 4 pages per document

    Error Handling

    Partial Failures: - Continue processing remaining images - Track failed extractions - Return partial results

    Response Format:

    {
  "results": {...},
  "successful_extractions": 45,
  "failed_extractions": 5,
  "failed_files": ["page_23.jpg", ...]
}

    Nolain OCR Backend API Usage

    This guide provides detailed information on how to interact with the Nolain OCR Backend API.

    Base URLs

    Environment Base URL
    Local Terminal (uvicorn on :8000) http://localhost:8000
    Local Docker (nginx) http://localhost/api
    VPS / Production https://nolainocr.com/api

    When using Docker or production, all API routes are prefixed with /api (nginx strips the prefix before forwarding to the backend). Exceptions: /webhook and /health are routed directly without the /api prefix.

    Do not call http://localhost/topup-packs without the /api prefix when using Docker; that hits the frontend, not the backend.

    Authentication

    Most endpoints require authentication via request headers:

    Header Description
    X-Access-Token Supabase JWT access token (preferred)
    X-User-Id User UUID (fallback if token unavailable)

    Obtain the access token from the POST /login or POST /auth/session response.

    Example:

    curl -X GET "{{BASE_URL}}/subscription-status" \
  -H "X-Access-Token: your_jwt_token" \
  -H "X-User-Id: your_user_id"

    Endpoints

    Health Check

    curl "{{BASE_URL}}/"

    Returns {"message": "Nolain OCR API is running"}.

    1. User Registration

    curl -X POST "{{BASE_URL}}/register" \
  -H "Content-Type: application/json" \
  -d '{
    "email": "user@example.com",
    "password": "your_password",
    "full_name": "John Doe"
  }'
    Field Required Description
    email Yes User email address
    password Yes User password
    full_name No User's full name

    2. User Login

    curl -X POST "{{BASE_URL}}/login" \
  -H "Content-Type: application/json" \
  -d '{
    "email": "user@example.com",
    "password": "your_password"
  }'

    Returns user ID, access token, and email confirmation status.

    3. Google OAuth

    Get redirect URL:

    curl "{{BASE_URL}}/auth/google?redirect_to=https://nolainocr.com/auth/callback"

    Verify session after OAuth callback:

    curl -X POST "{{BASE_URL}}/auth/session" \
  -H "Content-Type: application/json" \
  -d '{
    "access_token": "token_from_oauth",
    "refresh_token": "refresh_token_from_oauth"
  }'

    4. User Logout

    curl -X POST "{{BASE_URL}}/logout" \
  -H "X-Access-Token: your_jwt_token" \
  -H "X-User-Id: your_user_id"

    Cleans up all uploaded files for the user and clears the session.

    5. Password Reset

    Request reset email:

    curl -X POST "{{BASE_URL}}/reset-password" \
  -H "Content-Type: application/json" \
  -d '{"email": "user@example.com"}'

    Update password with tokens from email:

    curl -X POST "{{BASE_URL}}/update-password" \
  -H "Content-Type: application/json" \
  -d '{
    "password": "new_password",
    "access_token": "token_from_reset_email",
    "refresh_token": "refresh_token_from_reset_email"
  }'

    6. Upload PDF Files

    curl -X POST "{{BASE_URL}}/upload_pdf" \
  -H "X-Access-Token: your_jwt_token" \
  -H "X-User-Id: your_user_id" \
  -F "files=@/path/to/document.pdf"

    Multiple files:

    curl -X POST "{{BASE_URL}}/upload_pdf" \
  -H "X-Access-Token: your_jwt_token" \
  -H "X-User-Id: your_user_id" \
  -F "files=@/path/to/doc1.pdf" \
  -F "files=@/path/to/doc2.pdf"
    Field Required Description
    files Yes One or more PDF files (multipart/form-data)

    Response: - Single page: file_id is the filename (e.g., "image.jpg") - Multiple pages: file_id is a folder name (e.g., "upload_userid_timestamp") - PDFs are converted to page_N.jpg images automatically

    Page limits (enforced at upload):

    Tier Pages/Document Pages/Month
    Free 3 3
    Pro 50 1,500
    Pro Plus 200 10,000

    7. Upload Image Files

    curl -X POST "{{BASE_URL}}/upload_image" \
  -H "X-Access-Token: your_jwt_token" \
  -H "X-User-Id: your_user_id" \
  -F "files=@/path/to/image.jpg"

    Same behavior as PDF upload but for image files directly (.png, .jpg, .jpeg).

    8. Extract Text from Single Image

    Synchronous extraction — returns results immediately.

    curl -X POST "{{BASE_URL}}/extract_image" \
  -H "Content-Type: application/json" \
  -H "X-Access-Token: your_jwt_token" \
  -H "X-User-Id: your_user_id" \
  -d '{
    "file_id": "your_file_id_from_upload",
    "extraction_mode": "fast_extraction",
    "user_id": "your_user_id"
  }'
    Field Required Description
    file_id Yes Filename or folder path from upload
    extraction_mode Yes "fast_extraction" (only mode available)
    user_id Yes User ID (must match authenticated user)

    9. Extract Multiple Images (Async)

    Queues a Celery task and returns a task_id. Connect to the SSE stream for progress and results.

    curl -X POST "{{BASE_URL}}/extract_multiple_images" \
  -H "Content-Type: application/json" \
  -H "X-Access-Token: your_jwt_token" \
  -H "X-User-Id: your_user_id" \
  -d '{
    "folder_id": "upload_userid_timestamp",
    "extraction_mode": "fast_extraction",
    "user_id": "your_user_id"
  }'

    With template groups (combine pages into multi-page documents):

    curl -X POST "{{BASE_URL}}/extract_multiple_images" \
  -H "Content-Type: application/json" \
  -H "X-Access-Token: your_jwt_token" \
  -H "X-User-Id: your_user_id" \
  -d '{
    "folder_id": "upload_userid_timestamp",
    "extraction_mode": "fast_extraction",
    "user_id": "your_user_id",
    "template_group": [
      ["page_1.jpg", "page_2.jpg"],
      ["page_3.jpg"]
    ]
  }'
    Field Required Description
    folder_id Yes Folder from multi-page upload (must start with upload_)
    extraction_mode Yes "fast_extraction"
    user_id Yes User ID
    template_group No List of page groups (1–4 images per group)

    Response: Returns task_id. Listen for results:

    curl -N "{{BASE_URL}}/stream/{task_id}"

    SSE events contain status (processing, completed, failed), progress (0–100), and results on completion.

    10. Get Page Image

    Preview a specific page from an uploaded folder:

    curl "{{BASE_URL}}/get_page_image/upload_userid_timestamp/0" \
  -H "X-Access-Token: your_jwt_token"
    Parameter Description
    folder_id Folder name from upload
    page_number Zero-based page index (0, 1, 2, ...)

    Returns JPEG image with cache headers.

    11. Export Current Data

    Export the current extraction table as Excel or CSV:

    curl -X POST "{{BASE_URL}}/export_current_data" \
  -H "Content-Type: application/json" \
  -H "X-Access-Token: your_jwt_token" \
  -d '{
    "data": {
      "patient_name": ["John", "Jane"],
      "diagnosis": ["Flu", "Cold"]
    },
    "format": "excel",
    "filename": "my_export",
    "columns": ["patient_name", "diagnosis"]
  }'
    Field Required Description
    data Yes Columnar extraction data
    format No "excel" or "csv" (default: "excel")
    filename No Export filename (default: "extraction")
    columns No Subset of columns to include

    Returns file download. JSON export is handled client-side.

    12. Get Subscription Status

    curl "{{BASE_URL}}/subscription-status" \
  -H "X-Access-Token: your_jwt_token" \
  -H "X-User-Id: your_user_id"

    Returns plan tier, usage, limits, top-up credit balance, and Stripe subscription details.

    13. Get Subscription Limits

    curl "{{BASE_URL}}/subscription-limits"

    No auth required. Returns limits and pricing for all tiers.

    14. Create Checkout Session (Subscription)

    curl -X POST "{{BASE_URL}}/create-checkout-session" \
  -H "Content-Type: application/json" \
  -H "X-Access-Token: your_jwt_token" \
  -d '{
    "user_id": "your_user_id",
    "price_id": "price_xxx"
  }'

    Returns Stripe Checkout URL for subscription purchase.

    15. Update Subscription

    curl -X POST "{{BASE_URL}}/update-subscription" \
  -H "Content-Type: application/json" \
  -H "X-Access-Token: your_jwt_token" \
  -d '{
    "user_id": "your_user_id",
    "new_price_id": "price_xxx"
  }'

    Upgrades (Pro → Pro+) take effect immediately. Downgrades are scheduled at period end.

    16. Cancel Subscription

    curl -X POST "{{BASE_URL}}/cancel-subscription" \
  -H "X-Access-Token: your_jwt_token" \
  -H "X-User-Id: your_user_id"

    Schedules cancellation at the end of the current billing period.

    17. Create Billing Portal Session

    curl -X POST "{{BASE_URL}}/create-billing-portal-session" \
  -H "X-Access-Token: your_jwt_token" \
  -H "X-User-Id: your_user_id"

    Returns URL to Stripe Customer Portal for payment method and subscription management.

    18. Top-up Page Packs

    List available packs:

    curl "{{BASE_URL}}/topup-packs"

    Create top-up checkout:

    curl -X POST "{{BASE_URL}}/create-topup-checkout" \
  -H "Content-Type: application/json" \
  -H "X-Access-Token: your_jwt_token" \
  -d '{
    "user_id": "your_user_id",
    "pack_id": "topup_5"
  }'

    Confirm top-up after payment:

    curl -X POST "{{BASE_URL}}/confirm-topup-checkout" \
  -H "Content-Type: application/json" \
  -H "X-Access-Token: your_jwt_token" \
  -d '{
    "session_id": "cs_test_xxx"
  }'

    Top-up credits are consumed after monthly plan quota is exhausted. Free-tier users can also purchase top-ups.

    19. Stripe Webhook

    Called by Stripe, not by your application:

    POST /webhook

    In local development:

    stripe listen --forward-to localhost/webhook

    20. SSE Task Stream

    Real-time extraction progress:

    curl -N "{{BASE_URL}}/stream/{task_id}"

    No auth required. Events are JSON with status, progress, and results fields.

    API Endpoints Summary

    Method Endpoint Auth Description
    GET / No Health check
    POST /register No User registration
    POST /login No User authentication
    GET /auth/google No Google OAuth redirect URL
    POST /auth/session No Verify OAuth tokens
    POST /logout Yes Logout and file cleanup
    POST /reset-password No Request password reset
    POST /update-password No Update password with tokens
    POST /upload_pdf Yes Upload PDF(s)
    POST /upload_image Yes Upload image(s)
    GET /get_page_image/{folder_id}/{page_number} Optional Page preview image
    POST /extract_image Yes Sync single-image extraction
    POST /extract_multiple_images Yes Async batch extraction
    POST /export_current_data Yes Export table as Excel/CSV
    GET /subscription-status Yes Subscription and usage
    GET /subscription-limits No Plan limits for all tiers
    POST /create-checkout-session Yes Stripe subscription checkout
    POST /update-subscription Yes Upgrade/downgrade plan
    POST /cancel-subscription Yes Cancel subscription
    POST /create-billing-portal-session Yes Stripe billing portal
    GET /topup-packs No Top-up pack catalog
    POST /create-topup-checkout Yes Top-up Stripe checkout
    POST /confirm-topup-checkout Yes Confirm top-up payment
    POST /webhook Stripe sig Stripe webhook events
    GET /stream/{task_id} No SSE extraction progress

    Page Billing

    Pages are billed after extraction completes:

    1. Monthly plan quota is consumed first
    2. Top-up credits are used when monthly quota is exhausted
    3. Returns 402 Payment Required if both pools are empty

    Admin users (ADMIN_USER_ID env var) bypass all limits.

    Removed Endpoints

    The following endpoints existed in earlier versions but are no longer available:

    Endpoint Status
    GET /historical_names/{user_id} Removed
    GET /export_historical/{user_id}/{name} Removed — use POST /export_current_data
    POST /numerical-statistics Removed
    POST /categorical-*-statistics Removed
    POST /pearson-correlations Removed
    GET /task-updates/{task_id} Renamed to GET /stream/{task_id}
    GET /subscription-status/{user_id} Now GET /subscription-status (auth header)
    POST /cancel-subscription/{user_id} Now POST /cancel-subscription (auth header)

    Extraction modes new_historical and update_historical are no longer supported. Only fast_extraction is available.

    Quickstart: Local Terminal (Linux/Conda)

    This guide provides step-by-step instructions to run the Nolain OCR application locally on a Linux machine using Conda for environment management.

    Prerequisites

    1. Terminal: You need access to a terminal window.
    2. Git: Ensure Git is installed by running git --version.
    3. Conda: Ensure Anaconda or Miniconda is installed by running conda --version.
    4. Node.js: Ensure Node.js (version 18 or higher) is installed by running node --version.
    5. Redis: Ensure Redis is installed and running locally. You can check this by running redis-cli ping (should return PONG).

    Step 1: Open Terminal and Navigate

    1. Open your terminal application.
    2. Navigate to the directory where you want to store the project. For example, to use your Documents folder, run: bash cd ~/Documents

    Step 2: Clone the Repository

    1. Clone the project repository (replace <repository_url> with the actual URL): bash git clone <repository_url>
    2. Enter the project directory: bash cd nolain-ocr
    3. Verify you are in the correct directory by listing the files. You should see folders like backend, frontend, and files like docker-compose.yml: bash ls -F

    Step 3: Configure Environment Variables

    1. Create a new file named .env in the nolain-ocr directory by copying the template: bash cp ".env copy" .env
    2. Open the .env file using a text editor (e.g., nano): bash nano .env

    3. Ensure the file contains exactly the following values. Copy and paste these lines into the file:

      ```env SUPABASE_URL=your_supabase_url SUPABASE_ANON_KEY=your_supabase_anon_key VITE_SUPABASE_URL=your_supabase_url VITE_SUPABASE_ANON_KEY=your_supabase_anon_key MISTRAL_API_KEY=your_mistral_api_key

      STRIPE_SECRET_KEY=your_stripe_secret_key STRIPE_PUBLISHABLE_KEY=your_stripe_publishable_key STRIPE_WEBHOOK_SECRET=your_stripe_webhook_secret

      Stripe Price IDs (Get these from STRIPE_SETUP.md)

      STRIPE_PRO_PRICE_ID=price_... STRIPE_PRO_PLUS_PRICE_ID=price_... VITE_STRIPE_PRO_PRICE_ID=price_... VITE_STRIPE_PRO_PLUS_PRICE_ID=price_...

      FRONTEND_URL=http://localhost:5173

      Celery / Redis Configuration (Local)

      CELERY_BROKER_URL=redis://localhost:6379/0 CELERY_RESULT_BACKEND=redis://localhost:6379/0 `` 4. Save the file and exit the editor. If usingnano: - PressCtrl + OthenEnterto save. - PressCtrl + X` to exit.

    Step 4: Create Supabase Tables

    You need to create the necessary tables in your Supabase database.

    1. Go to your Supabase Dashboard.
    2. Navigate to the SQL Editor.
    3. Create a new query and paste the contents of the following files (found in the backend/sql/ directory):
      • create_subscriptions_table.sql
      • create_historical_extractions_table.sql
      • create_user_sessions_table.sql
    4. Run the queries to create the tables.

    Step 5: Stripe Setup

    Before running the application, you must configure your Stripe account.

    1. Follow the instructions in STRIPE_SETUP.md to:
      • Get your API Keys.
      • Create your Products and get Price IDs.
      • Set up the Stripe CLI for local webhooks.
    2. Update your .env file with the Price IDs and API Keys obtained from Stripe.

    Step 6: Backend Setup (Terminal 1)

    Do not close the current terminal. We will use this terminal to run the Backend.

    1. Create a new Conda environment named nolain-ocr with Python 3.11: bash conda create -n nolain-ocr python=3.11 -y
    2. Activate the Conda environment: bash conda activate nolain-ocr
    3. Navigate to the backend directory: bash cd backend
    4. Install the required Python dependencies: bash pip install -r requirements.txt
    5. Start the Backend server: bash uvicorn main:app --reload --host 0.0.0.0 --port 8000 You should see logs indicating the server is running at http://0.0.0.0:8000.

    Step 5: Celery Worker Setup (Terminal 2)

    1. Open a NEW terminal window.
    2. Navigate to the project directory: bash cd ~/Documents/nolain-ocr (Adjust the path if you cloned it somewhere else)
    3. Activate the same Conda environment: bash conda activate nolain-ocr
    4. Start the Celery worker: bash celery -A backend.core.celery_app.celery_app worker --loglevel=info You should see logs indicating the worker is ready and connected to Redis.

    Step 6: Frontend Setup (Terminal 3)

    1. Open a NEW terminal window.
    2. Navigate to the project directory: bash cd ~/Documents/nolain-ocr
    3. Navigate to the frontend directory: bash cd frontend
    4. Install Node.js dependencies: bash npm install
    5. Start the Frontend development server: bash npm run dev You should see a URL like http://localhost:5173.

    Step 7: Access the Application

    1. Open your web browser (Chrome, Firefox, etc.).
    2. Type the following URL in the address bar and press Enter: http://localhost:5173
